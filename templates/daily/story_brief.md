# 生活日常 敘事簡報（template: daily）

## 適用情境
- 沒有明確任務目標、記錄一天／一段生活的 vlog：起床、做飯、出門走走、跟人互動、睡前碎念。
- 逐字稿語氣鬆散、跳題、有情緒起伏，但沒有「要完成某件事」的主線。
- 何時不該用：其實是去探店（用 food）、去旅行（用 travel）、或坐下來認真講一個觀點（用 talking）。
- 與 travel 的區分：daily 不在乎去了哪裡，在乎的是「今天的感覺」；地點只是背景。

## 素材不符時
若逐字稿其實有清楚的單一任務或主題（例如整支在評測一個產品），回報「素材有明確主線，不符 daily 的鬆散日記感」，改用對應模板或退用通用結構，不要把有主線的內容硬剪成流水日記。

## 章節結構
以「時間或情緒段落」為鬆散章節（傾向，非鐵律）：
- 早上 → 中午 → 下午 → 晚上，或以情緒轉折分段（平靜 → 小插曲 → 收心）。
- 章節之間允許鬆、允許留白，不要每段都有目的性——那是日常的質感。
- 顺剪約束下：完全依素材時間順序，日常片本來就是順著一天走，最自然。
- 不要硬套 Hook→Payoff 的戲劇弧線，日常可以沒有高潮。

## 選段原則
- radio-edit 偏寬鬆：這是唯一要「刻意保留呼吸感」的情境。留下自然的停頓、語助詞、一兩秒的沉默，不要剪成密不透風的資訊流。
- 必留：情緒瞬間（笑、嘆氣、突然的真心話）、生活細節的可愛之處。
- 可刪：真正的空轉重複、明顯的口誤重來。
- 句子完整性不可妥協，但「未說完就被情緒打斷」的自然句也可保留，因為那就是日常。

## Hook 選句風格
- 2 段。挑今天最有趣或情緒最濃的兩個瞬間（笑點、突發狀況、一句真心話）。
- 語氣要自然、像跟朋友分享，不要選聽起來像結論或宣告的句子。
- 避免：正經的資訊句、把一天總結完的句子（會破壞「跟著過一天」的期待）。

## B-roll 指導
- 中密度：蓋畫面是為了氣氛，不是為了資訊。密度刻意低於美食／旅遊（已設 2.5/min）。
- 何時蓋：講到某個物件、某個空間、某件小事時，補一個生活感的畫面即可。
- 絕不蓋：情緒獨白與真心話的臉——那是日常片的核心，讓觀眾看到表情。
- 偏好鏡頭：生活小物、光影、寵物、手部動作等有溫度的近景；不要冷冰冰的資訊圖。

## 本情境禁忌
1. 把停頓與呼吸全剪掉，變成高資訊密度的口播，日常的鬆感就消失了。
2. 硬加戲劇性高潮或懸念，讓平淡的一天顯得做作。
3. B-roll 蓋太滿，觀眾感覺不到「這個人此刻的狀態」。
4. 為了節奏切掉情緒句的尾巴，情緒被腰斬比冗長更傷。
